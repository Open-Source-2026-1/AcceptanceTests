Pruebas de Aceptación – SkillSwap

Este repositorio contiene las pruebas de aceptación del proyecto SkillSwap (Innovify), desarrolladas en base a las historias de usuario definidas para la plataforma.

¿Qué valida este repositorio?

Las pruebas de aceptación están escritas en Gherkin (.feature) y cubren de manera integral el comportamiento del sistema según las 35 historias de usuario, organizadas en los siguientes módulos funcionales:

Funcionalidades Cubiertas Gestión de cuentas y perfiles Registro con correo institucional (.edu.pe) Inicio de sesión con roles (Estudiante / Profesor) Configuración de perfil, habilidades y verificación institucional Gestión de disponibilidad del tutor Búsqueda y emparejamiento Búsqueda de tutores por cursos Aplicación de filtros (valoración, universidad) Visualización de perfiles públicos Coordinación de tutorías Envío, aceptación y cancelación de solicitudes Chat interno asincrónico Envío de archivos (PDF, imágenes) Ejecución de sesiones Videollamadas integradas Compartir pantalla en tiempo real Aseguramiento académico Creación de quizzes por profesores Asignación y resolución de evaluaciones Validación automática de resultados Calificación y monetización Sistema de reseñas y reputación Donaciones mediante pasarela de pago Billetera virtual y gestión de retiros Dashboard y moderación Panel docente con métricas académicas Reporte de usuarios y resolución de disputas Backend e integraciones Validación de correos institucionales Integración con APIs (pagos, WebRTC, almacenamiento) Endpoints de analítica para dashboard Experiencia de usuario Landing page informativa Sección “Sobre nosotros” Animaciones y microinteracciones Cambio dinámico de idioma (ES / EN) Propósito

El objetivo de estas pruebas es garantizar que cada funcionalidad implementada cumpla con sus criterios de aceptación, asegurando una experiencia completa, segura y escalable para todos los usuarios de la plataforma.

Tecnologías Gherkin – Definición de pruebas Cucumber – Ejecución de escenarios GitHub – Control de versiones
